Most platforms stop at pixels and protocols. OpenXP starts with how humans feel.

We design for what people should feel, and then we build experiences with tools that only speak in what machines should do.

Experience as code

The OpenXP experience format is the open standard for describing immersive experiences. Human-readable, formally specified, deterministically executable. Same state and same event produce the same transition — always. No loops, no hidden logic, no surprises: what you read is what runs, on a laptop, in a simulator, or in the venue.

Design for how humans feel

Human perception is a core touchpoint in OpenXP — as real as an NFC reader or LED wall. You can trigger transitions on wonder, shape scenes with calm, and adapt entire journeys to the emotional arc of your guests.

Every protocol. One interface.

Every protocol, with simulation mode. If it has a wire, OpenXP can talk to it. Missing hardware never crashes the system — connectors degrade gracefully, log warnings, and continue.

Owned by the industry, not by OpenXP

The OpenXP experience format is a portable, vendor-neutral way to describe immersive physical-digital experiences. The specification is a public good — maintained in the open, owned by the industry, and available to anyone who wants to build on it. The format is published under Creative Commons CC-BY-4.0; the reference runtime, connector fabric, and bridge are open-source and free.

Build. Run. Scale.

Design it, run it, scale it. Every module has a well-defined boundary — run one experience standalone, swap a piece out, or connect them end-to-end. An open standard with reference implementations, a free-to-use tools suite, and an optional cloud for multi-venue operations.
